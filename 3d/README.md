# 3D

- **[biscotti-head.blend](biscotti-head.blend)**: Biscotti's head, in Blender.

Model by Tony Mora. Design by Jared Chapman. Pasquale made some tweaks to get a
bit closer to the silhouette.

- **[biscotti-puppet-head.blend](biscotti-puppet-head.blend)** / **[.usdz](biscotti-puppet-head.usdz)**:
  the puppet version of him, as the iOS app's singing door draws him on
  20 Oct 2026: the flip-top skull and jaw, floppy ears, heart tongue and
  throat, the cowlick, Pasquale's origami Robin Hood cap with the feather in
  its brim. Exported straight from the app (`BISCOTTI_EXPORT=1` in a debug
  build writes it as USDZ); the parts are named (`top`, `jaw`, `eyeL`,
  `earR`, `hat`, `feather`, `tongue`…). Stand-in geometry, not a sculpt.
